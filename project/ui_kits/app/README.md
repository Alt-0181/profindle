# Profindle App UI Kit

## Overview
High-fidelity component kit for the Profindle web application. Built with React + Babel inline, using the Midnight Teal design system.

## Components
- `Header.jsx` — Top navigation with logo, search, and user actions
- `HeroSection.jsx` — Landing hero with headline, CTA, and stat strip
- `ProfileCard.jsx` — Professional profile card (interactive)
- `SearchBar.jsx` — Search input with filter chips
- `PremiumBadge.jsx` — Premium upgrade prompt card

## Screens in index.html
1. **Discovery Feed** — Browse professional profiles
2. **Profile View** — Expanded individual profile
3. **Sign Up** — Onboarding form

## Design Width
1280px desktop
