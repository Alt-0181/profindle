Rich Menu System

Two rich menus for the Profindle Official Account. Followers land on the Main menu (Manual / Chat with us). Tapping Manual switches to a sub-menu with four self-serve guides — getting started, finding providers, VIP status and the LINE-connect UID.

Export & implementation

1. Export each menu as PNG/JPEG at its actual pixel size — 2500 × 843 for the main menu, 2500 × 1686 for the Manual sub-menu. The frames above are pinned to those exact aspect ratios so what you see is what LINE renders.

2. Upload via Messaging API — POST /v2/bot/richmenu creates each menu, then POST /v2/bot/richmenu/{richMenuId}/content uploads the image. Each cell maps to a rectangular bounds region paired with one of: postback, message, uri, or richmenuswitch.

3. Switch menus seamlessly with the richmenuswitch action — it swaps the menu without sending a chat bubble, so jumping Manual ↔ Main feels native.

4. Postback replies are the magic. The four Manual cells (Get started / Find provider / VIP status / Get UID) all return Flex Messages — server reads the postback data string and replies inline. No new screens to design.

5. Set rm-main as default on the bot via POST /v2/bot/user/all/richmenu/{richMenuId}. Sub-menus are short-lived — entered by a tap, exited by Back.
