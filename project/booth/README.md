# Profindle — Expo Booth (NOT part of engineering handoff)

> ⚠️ **This folder is out of scope for the engineering handoff.**
> Everything here is marketing / event material for the Bangkok expo — booth
> graphics, pitch scripts, print specs. Developers building the product should
> ignore this folder. The product handoff is `design_handoff_profindle/` +
> `HANDOFF_NOTES.md` only.

## Contents

```
booth/
├── README.md            ← this file
├── EXPO_PITCH.md        ← sales pitches + tech reference (TH / EN)
├── Booth Design.html    ← booth visual design: mockup, flat artwork, print specs
└── assets/              ← brand assets used by Booth Design.html (logos, tokens)
```

## The booth

- **Stand type:** 2×2 m corner shell scheme (Octanorm-style white system panels)
- **Walls:** back wall + one side wall, white system panels, ~2.5 m tall
- **Fascia:** header band across the top with company name + booth number
- **Brand:** Profindle "Midnight Teal" CI (deep teal + amber accent)

## What gets printed

| Piece | Size | Material |
|---|---|---|
| Fascia graphic | per organizer fascia spec (~2.0 × 0.3 m) | adhesive vinyl / inkjet |
| Back wall backdrop | 2.0 × 2.4 m (one piece or per-panel) | fabric / PVC backdrop |
| Side wall graphic | 1.0 × 2.4 m | fabric / PVC backdrop |
| Roll-up standee | 0.85 × 2.0 m | standee + vinyl print |
| QR table card | A5 | 350 gsm card, matte |

Open `Booth Design.html` for the full design with dimensions and color codes.
