Export & implementation

1. Export each menu as a PNG/JPEG at its actual pixel size (2500 × 843 for compact, 2500 × 1686 for large). The frames above are already at the exact LINE aspect ratios — designers can mirror this in Figma.

2. Upload via LINE Messaging API — POST /v2/bot/richmenu for each menu, then POST /v2/bot/richmenu/{richMenuId}/content with the PNG. Each cell is a bounds region (x, y, w, h in pixel space) paired with an action.

3. Switch menus with the richmenuswitch action type — it switches without firing a postback or message bubble, so the UX feels native.

4. Per-user menus. Set rm-main as the default on the bot; flip a user to rm-provider when they finish provider registration via POST /v2/bot/user/{userId}/richmenu/{richMenuId}.

5. EN/TH labels. Each cell carries both languages already. We can ship one bilingual menu or two parallel menus and switch by locale.
